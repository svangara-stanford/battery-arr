# Data directory

Do not commit raw or processed battery datasets.

Expected local layout:

```text
data/raw/chueh_toyota_fast_charge/       # manually downloaded MatR batches or CSVs
data/processed/chueh_toyota_fast_charge/ # generated normalized tables
data/demo/                               # synthetic smoke-test data generated by make demo
```

The prototype writes normalized CSV files with this schema:

- `cell_metadata.csv`: one row per cell, including `cell_id`, `batch_id`, `cycle_life`, and optional protocol columns.
- `cycle_summary.csv`: one row per cell-cycle, including `cycle_index`, discharge capacity, charge capacity, resistance, temperature, and charge-time summaries where available.
- `splits.csv`: deterministic train/validation/test split assignments.
